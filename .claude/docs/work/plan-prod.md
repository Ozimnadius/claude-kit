## На что смотреть при ревью

Случаи, которые спек подразумевает, а прямые тесты задач легко пропустят; у каждого — тест в своей задаче.
1. Отмена после остановки (`--abort`) возвращает к HEAD только записанное синхронизацией: наши незакоммиченные правки и совмещённое
   целы (48.7).
2. Синхронизация оборвалась после записи части файлов — повтор забирает их коммитом синхронизации, а не принимает за нашу
   незакоммиченную правку (тест 48.3; 48.6–48.8 его не ломают).
3. По FTP скачали папку целиком: архивы, файлы больше 10 МБ, с секретом, под `.gitignore` и «Не выкладывать» в коммит не идут,
   отслеживаемые из них возвращены из HEAD (48.8).
4. По FTP скачанное с CRLF при LF в git — не «изменено без нас» (48.8).
5. Старого имени `prod-entry.js` и слова «вход» в выводе не осталось: тесты, заглушка, навык и README зовут `prod-sync.js` (48.6, 48.9,
   48.11).
