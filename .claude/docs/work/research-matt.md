# Сводка глубокого исследования перед выпуском kit 3.3.0 (2026-10-28)

Источники: три отчёта исследования (A — навыки Мэтта против kit, B — стыки kit, C — платформа Claude Code; рабочие материалы, в git не кладутся). Повторы сведены; в скобках — номера находок в отчётах.

## Что подтвердилось (проблем нет)

- Новые стражи не ломают ни одного сценария kit и aspro: 48 команд и 36 путей из навыков — без ложных отказов (B).
- `claude plugin disable superpowers… --scope project` при superpowers на уровне пользователя работает; `false` проекта перекрывает `true` пользователя (C).
- `.claude/settings.json` в kit-проектах вне git — предпосылка Т-2 верна; решение пользователя 2026-10-28 — так и оставить.
- Хуки соответствуют контракту PreToolUse; PreToolUse срабатывает и на `mcp__ccd_session__start_session` (C).
- Вывод `session-start.js` в худшем случае — 7 817 символов при пределе 10 000 (C).
- guard-matt — около 50 мс на вызов (почти целиком запуск node) (B).
- В навыках Мэтта 1.3.1 нет конструкций, которые работают только при настоящем вызове (`!`команда``, `$ARGUMENTS` и т. п.); хуков, агентов, MCP у плагина нет (A, C).
- Журнал с папками Мэтта: STAGE со скобками и путём, DOCS-папки, перенос обеих папок в archive/, NEXT с путём — работают (опыт B).
