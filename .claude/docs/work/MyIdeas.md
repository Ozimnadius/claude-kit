# Замечания и идеи

## Что не нравится сейчас в плагине

- [x] 1. Режим PHP-консоли в Битрикс, постоянно приходится нажимать руками выполнить, не удобно и долго. Может вообще
  стоит отказаться от консоли и делать это через файлы, которые удалять после проведенных работ. В общем надо обдумать
  этот момент.
- [x] 2. Нужно автоматизировать Excluded Paths, чтобы я руками их не менял каждый раз.
- [x] 3. Хаос в папке docs.
- [x] 4. Нет понятия какие планы, спеки и т.д устарели, возможно стоит придумать что-то типа архива.
