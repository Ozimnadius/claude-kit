## Условия

- Файл можно использовать, копировать, распространять и изменять на условиях LGPL 2.1 или более поздней версии.
- Уведомления об авторских правах и лицензии исходных файлов приведены в шапке `xmerge.php` **дословно**: четыре блока
  `/* … */` (по одному на `xmerge.c`, `xdiffi.c`, `xprepare.c`, `xutils.c`) — байт в байт шапки этих файлов в git, на
  английском, вместе с адресом автора LibXDiff. Сверены с исходниками git (ветка master) 18.10.2026. Перевод их смысла —
  отдельно, ниже дословных блоков; он справочный и уведомления не заменяет. Дословные блоки не менять.
- Изменённый файл помечается: что и когда изменено (раздел «Изменено» в шапке файла, после дословных блоков). Меняя файл
  дальше, допишите туда свои изменения и год.
- Вместе с файлом распространяется полный текст лицензии (`lib/LICENSE-LGPL-2.1.txt`, см. «При выпуске плагина»). Папку
  инструмента копируют на сайт целиком — текст лицензии уезжает вместе с `xmerge.php`.
- Гарантий нет — ни от авторов исходников, ни от авторов перевода.

## Остальной код инструмента

Остальные файлы (`merge.php`, `lib/*.php` кроме `xmerge.php`, `integration/aspro_merge.php`, `README.md`) — MIT. Они
только вызывают функции `xmerge.php` и не являются переводом xdiff. Файл `xmerge.php` подключается отдельно
(`lib/bootstrap.php`) и поставляется исходным текстом, поэтому пользователь может заменить его своей изменённой версией —
это условие LGPL для программы, которая пользуется библиотекой.

## Что изменено относительно исходников git

Перевод сделан в 2026 году авторами aspro-merge:

- перевод с C на PHP 8.1: записи (строки вместе с `"\n"`) хранятся строками PHP, классы одинаковых строк — массивами PHP
  вместо хеш-таблиц xdiff (`xdl_prepare_env`);
- оставлено только то, что нужно, чтобы совпасть с `git merge-file` с настройками по умолчанию: алгоритм Myers с
  эвристиками xdiff (`xdl_split`, `xdl_recs_cmp`, `xdl_cleanup_records`, `xdl_trim_ends`, `xdl_change_compact`) без
  patience/histogram, без indent heuristic и без флагов игнорирования пробелов; слияние `xdl_merge` (уровень EAGER для
  стиля diff3 и ZEALOUS_ALNUM для стиля merge, `xdl_refine_conflicts`, `xdl_simplify_non_conflicts`,
  `xdl_fill_merge_buffer`), маркеры как у git;
- добавлены свои функции: `am_split` (разбор текста на записи), `am_merge` (обёртка над строками), `am_to_lf`,
  `am_is_crlf` и `am_unified` (унифицированный diff поверх `am_xdiff`; это не перевод `xemit.c`);
- функции и константы — в пространстве имён `AsproMerge`.

Результат сверяется с `git merge-file` 2.54: эталонные случаи — `lib/selftest-cases.json` (их проверяет
`merge.php selftest`).

## При выпуске плагина

В репозитории разработки полного текста лицензии нет — он лежит только в плагине: файл
`plugins/aspro/skills/aspro-merge/tool/lib/LICENSE-LGPL-2.1.txt` (в поставке — `tool/lib/LICENSE-LGPL-2.1.txt`, рядом с
`xmerge.php`). Перед первым выпуском его кладут туда вручную — текст без изменений с
<https://www.gnu.org/licenses/old-licenses/lgpl-2.1.txt> (в нём есть строки «GNU LESSER GENERAL PUBLIC LICENSE» и
«Version 2.1»). Скрипт выпуска при записи (без `--dry`) проверяет, что файл на месте и это LGPL 2.1, иначе останавливается
с подсказкой и ничего не пишет; при замене папки скила файл сохраняется (как все `LICENSE*`). В описании плагина стоит
упомянуть, что `tool/lib/xmerge.php` распространяется по LGPL-2.1-or-later, а остальное — по MIT.
