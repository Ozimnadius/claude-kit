# Края большой работы

Читай, когда до края дошло (п. 8 ядра `/kit:matt`).

- **Файла навыка нет** (`matt-skill.js` — код 3) — скажи пользователю: пусть введёт `/mattpocock-skills:<имя>` сам; сверь правила kit с версией плагина (имена навыков, пути, поля тикетов).
- **Исполнитель оборвался** — тикет остаётся `claimed`: сними `claimed` (тикет — снова во фронт) или спроси пользователя.
- **Общие файлы** (карта, глоссарий) параллельных тикетов — в коммите тикета допустимы; коммиты — по одному, только в общей сессии.
- **Терминал** (нет `mcp__ccd_session__start_session`): тикеты с пользователем (грилинг, спек, нарезка, прототип) ведёт сама общая сессия или пользователь открывает вторую сессию с заданием п. 5; субагентам — только тикеты без пользователя: у субагентов нет AskUserQuestion.
- **Сжатие контекста** — восстанови по «Сейчас» журнала, карте и статусам тикетов; снова `node "${CLAUDE_PLUGIN_ROOT}/scripts/matt-skill.js" <имя>` и перечитай файл навыка, которым идёт работа; без пользователя — и `${CLAUDE_PLUGIN_ROOT}/skills/matt/reference/autonomous.md`. Навыки, вызванные инструментом Skill (`mattpocock-skills:<имя>`, которые модель зовёт сама), платформа прикрепляет заново; прочитанные файлом — нет, их перечитывай.
